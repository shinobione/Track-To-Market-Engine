ARCHITECTURE TECHNIQUE & LOGIQUE MÉTIER : OUTIL FLOW — SHINOBIWAN RELEASE PACK GENERATORDestinataire : ChatGPT / Dev AIObjet : Cahier des charges complet, règles de génération et cartographie React/TypeScript du projet Outil FLOW (SHINOBIWAN Release Pack Generator).1. CARTOGRAPHIE ARCHITECTURALE DU CODEBASELe projet est une application React Single-Page (SPA) développée en TypeScript s'appuyant sur le SDK Google Flow (Google AI Studio / Flow SDK) et structurée selon le découpage suivant :PlaintextOutil FLOW/
├── types.ts                   # Interfaces TS (Inputs, Outputs, Session, Error handling)
├── App.tsx                    # Shell principal, Sidebar Inputs & State global
├── Readme.txt                 # Documentation projet
└── components/
    ├── Primitives.tsx         # Composants UI de base (Dark Theme inputs, Modals, Buttons)
    └── OutputDisplay.tsx      # Panneau de résultats (Grid 4-Covers, Actions, Textes, Export)

la gestion d'erreur fine (séparation des erreurs SDK, formatage JSON, prompts vides).components/Primitives.tsxComposants d'interface réutilisables basés sur le design system Flow Dark UI (couleurs LOGIQUE MÉTIER & PARAMÈTRES D'ENTRÉE (App.tsx / types.ts)Chaque génération exploite les variables saisies dans App.tsx :Titre (title) : Orthographe exacte obligatoirement transmise dans les prompts visuels.Genres (genres) : Tableau de sous-genres triés alphabétiquement (Classical, Club Electronic, Drill, Electro-Funk, G-Funk, Glitch Hop, Glitchcore, Hip Hop, Hyperpop, Phonk, Plunderphonics, Pop, R&B, Rock, Techno, Trap, West Coast Hip-Hop, etc.).Suno Prompt / Ambiance sonore (audioStyle) : Prompt audio d'origine permettant d'inférer l'énergie et la signature sonore.Paroles (lyrics) : Texte source exploité pour extraire l'arc émotionnel et les thématiques.Direction Artistique (artDirection) : Mots-clés de style visuel (cyberpunk, néon, argentique, brutaliste, etc.).Logo Artiste (logo) : Image de référence du logo "SHINOBIWAN" à intégrer subtilement en tant qu'élément du décor.3. RÈGLES D'EXÉCUTION DU SYSTÈME & OUTPUTS (OutputDisplay.tsx)✅ OUTPUT 1 — COVER ART PROMPT & MOTEUR VISUELFormat natif : 16:9 Paysage (Style thumbnail YouTube / Artwork cinématique).Hiérarchie Visuelle du Prompt :Titre du morceau : Sujet principal et élément typographique dominant (néon, inscription 3D, tag).Logo Artiste : Élément secondaire discret d'ambiance intégrée (autocollant, filigrane néon, gravure, tag mural) sans jamais masquer le titre ni déformer le logo SHINOBIWAN.Composition : Cadrage, éclairage, palette de couleurs, grain et effets (bloom, aberration chromatique).Langue du Prompt : Rédigé impérativement en Anglais.✅ OUTPUT 2 — SOUNDCLOUD & SOCIAL RELEASE PACKLangue : Rédigé impérativement en Anglais.Description SoundCloud :Longueur : 140 caractères maximum.Contenu : Thème, genre, progression d'énergie, signature vocale.Signature obligatoire finale : Thx for listening😁👍— SHINOBIWANTags Algorithmiques (15 à 20) :Format : Minuscules uniquement (lowercase).Ordre : Genres principaux $\rightarrow$ Sous-genres $\rightarrow$ Émotion/Mood $\rightarrow$ Contexte d'écoute (night drive, club, festival).Social Media Caption :Accroche courte (1 à 2 lignes) captivante et moderne pour Instagram/TikTok/X.4. GARDE-FOUS ET BINDINGS DU CODEBASEZero Preamble : Les fonctions de génération renvoient directement les structures JSON/Textes exploitables sans bavardage.Boutons de Régénération Ciblée : Chaque section de OutputDisplay.tsx possède son propre hook de rafraîchissement (regenerateCoverPrompt, regenerateSoundcloudDesc, regenerateSocialCaption).Gestion Réseau & Erreurs : App.tsx capture et affiche les erreurs du SDK Flow (saturation, crédits, prompt vide) de manière explicite.Transparence du Canvas : Les déclinaisons de visuels 1:1 et 9:16 conservent la référence d'image originale sans altérer la palette de couleurs.
