## Gate A — Local Draft

1. Start `local-ai/START_LOCAL_AI.bat`.
2. Verify Local Draft is detected as ready.
3. Generate one Local Draft batch.
4. Confirm every generated card is visibly labelled `DRAFT`.
5. Adapt 1:1 + 9:16 and create an 8 s teaser.
6. Export `DRAFT` ZIP.
7. Verify `release-pack.json` contains `releaseStatus: "draft"` and `publishToStudio: false`.

## Gate B — Cloud Draft

1. Generate one Cloud Draft batch if quota is available.
2. Confirm cards and selected-source status are `DRAFT`.
3. Confirm the UI does not offer a FINAL export for the Cloud source.

## Gate C — Final Premium

1. Copy the FINAL cover prompt.
2. Generate one cover externally with ChatGPT Images / Google Flow / Gemini.
3. Import it into Track-To-Market.
4. Confirm the card and finality gate show `FINAL`.
5. Adapt 1:1 + 9:16.
6. Create teaser if wanted.
7. Export `FINAL` ZIP.
8. Verify `release-pack.json` contains `releaseStatus: "final"` and `publishToStudio: true`.

## Gate D — Regression

- input autosave survives refresh;
- logo upload remains intact;
- SoundCloud/caption targeted regeneration works;
- favicon remains present;
- mobile layout remains usable;
- no LaunchPAD / R2 / Studio canonical write occurs from a DRAFT path.

V0.1.4 is considered validated only after Gate A + Gate C pass on the real machine/browser.
