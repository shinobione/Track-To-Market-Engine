# Changelog

## 0.1.0 — 2026-08-11

### Added
- Vite + React + TypeScript standalone application.
- GitHub Pages deployment workflow.
- Local deterministic release-copy engine.
- Local Canvas 2D artwork engine with four 16:9 variations.
- Seed-locked 1:1 and 9:16 adaptations.
- Optional local artist-logo composition.
- Eight-second local WebM teaser generation via MediaRecorder.
- Complete ZIP export including `release-pack.json`.
- Targeted prompt / SoundCloud / caption regeneration.
- Generation cancellation control.
- Responsive UI and local-only session stats.
- Studio bridge contract and integration documentation.

### Changed from FLOW prototype
- Removed runtime dependency on `flow-sdk`.
- Replaced Flow media picker with browser file input.
- Replaced Flow download with browser-native Blob downloads.
- Replaced cloud image/video generation with honest local engines to preserve zero-cost GitHub Pages operation.
